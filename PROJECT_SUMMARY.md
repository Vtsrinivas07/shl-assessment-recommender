## Quick Start

### 1. Setup

```bash
# Create virtual environment
python -m venv venv
venv\Scripts\activate  # Windows

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env and add your GROQ_API_KEY
```

### 2. Data Pipeline

```bash
# Scrape catalog
python -m app.scraper

# Build index
python -m app.index_builder
```

### 3. Run API

```bash
# Development
python run.py

# Production
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 4. Test

```bash
# Health check
curl http://localhost:8000/health

# Chat
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"I need to hire a Java developer"}]}'

# Run tests
pytest tests/ -v
```

## Key Features

### 1. Stateless Architecture
- Every request contains full conversation history
- No server-side session storage
- Horizontally scalable

### 2. Grounded Responses
- All recommendations backed by retrieved catalog evidence
- URL validation ensures only shl.com links
- No hallucinated products or URLs

### 3. Hybrid Ranking
- Combines semantic similarity (70%) with keyword overlap (30%)
- Improves relevance over pure semantic search
- Handles both natural language and keyword queries

### 4. Security
- Prompt injection resistance
- Off-topic request refusal
- URL domain validation
- Input sanitization

### 5. Conversation Management
- Intent detection for appropriate flow
- Clarification for vague queries (max 2 per conversation)
- Refinement support for constraint updates
- Comparison support for assessment details
- Automatic conversation completion

## API Endpoints

### GET /health
Returns API health status.

**Response:**
```json
{
  "status": "ok"
}
```

### POST /chat
Processes conversation and returns recommendations.

**Request:**
```json
{
  "messages": [
    {"role": "user", "content": "I need to hire a Java developer"},
    {"role": "assistant", "content": "What seniority level?"},
    {"role": "user", "content": "Mid-level"}
  ]
}
```

**Response:**
```json
{
  "reply": "Here are 5 suitable assessments...",
  "recommendations": [
    {
      "name": "Java 8 (New)",
      "url": "https://www.shl.com/solutions/products/java-8/",
      "test_type": "K"
    }
  ],
  "end_of_conversation": false
}
```

## Validation Rules

### Request
- Messages array must not be empty
- Roles must be "user" or "assistant"
- Roles must alternate
- Last message must be from user
- Content must not be empty

### Response
- Reply must not be empty
- Recommendations: 0-10 items
- When clarifying/refusing: empty recommendations
- When recommending: 1-10 items
- All URLs must be from shl.com
- Test types: K, A, P, or B

## Troubleshooting

### "FAISS index not found"
Run the data pipeline:
```bash
python -m app.scraper
python -m app.index_builder
```

### "GROQ_API_KEY is required"
Add your API key to .env file:
```
GROQ_API_KEY=your_actual_api_key
```

### Slow responses
- Check Groq API status
- Reduce RETRIEVAL_K in config
- Ensure FAISS index is loaded
